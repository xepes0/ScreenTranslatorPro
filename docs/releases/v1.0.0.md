# Screen Translator Pro v1.0.0 (Build 1)

首个正式版本。版本号与构建号从 `1.0.0 (1)` 开始。

- 使用系统相册选择截图，在 App 内识别、翻译并查看原位回填结果。
- 支持快捷指令「截屏 → 翻译截图 → 快速查看」，可绑定背部轻点等触发方式。
- 提供本地 OCR、百度、DeepL 和 OpenAI-Compatible 等翻译服务选项；API 密钥保存在 iOS Keychain。
- 设置页与主页采用蓝紫色界面和选定的应用图标。

下载 `ScreenTranslatorPro-v1.0.0-build1-unsigned.ipa`。这是未签名 IPA，需要使用自己的证书与描述文件签名后安装。支持 iOS 18.0 及更新版本。
