# 屏幕翻译 v1.0.1 (Build 2)

这个版本将应用显示名称改为「屏幕翻译」，保留现有 Bundle ID 与快捷指令流程。

- 设置页加入第三方翻译的数据发送说明和逐服务授权；未授权时不会发起远程翻译请求。
- 加入隐私政策、隐私清单与清除本机数据入口。
- 移除未使用的私有 API 遗留代码。
- 保留截图选择、文字识别、原位译图和「截屏 → 翻译截图 → 快速查看」流程。

下载 `ScreenTranslatorPro-v1.0.1-build2-unsigned.ipa`。这是未签名 IPA，需要使用自己的证书和描述文件签名后安装；不是 App Store 分发包。最低支持 iOS 18.0。
